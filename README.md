# Zealep Soluciones - Landing Page

## Descripción General

Sitio web corporativo de **Zealep Soluciones**, una empresa peruana de desarrollo de software, aplicaciones web, soluciones móviles, integraciones y consultoría tecnológica. La página está diseñada para transmitir confianza, claridad y capacidad técnica desde el primer vistazo, guiando al visitante hacia el contacto comercial.

El objetivo principal de esta landing page es presentar la propuesta de valor de Zealep de forma moderna, directa y convincente: software a medida para empresas que necesitan vender mejor, operar con más eficiencia y crecer con herramientas digitales confiables.

## Diseño y Estilo

### Identidad Visual Renovada

La versión actual deja atrás el estilo oscuro tipo "Tokyo Night" y adopta una identidad más corporativa, tecnológica y cercana. El diseño combina un hero visual de alto impacto, fondos oscuros con fotografía institucional, tarjetas claras para lectura rápida y acentos cálidos para destacar acciones importantes.

### Paleta de Colores

### Características de Diseño

- **Hero de alto impacto**: fondo fotográfico con overlay oscuro, ilustración tecnológica y mensaje comercial claro.
- **CTA orientado a conversión**: botón principal "Solicitar cotización" y botón secundario "Ver servicios".
- **Indicadores de confianza**: métricas visibles como años de experiencia, soluciones a medida y soporte en Perú.
- **Glassmorphism controlado**: elementos translúcidos en el header, badges y bloques flotantes del hero.
- **Tarjetas de servicios renovadas**: diseño claro, etiquetas de categoría y borde superior con acento visual.
- **Responsive Design**: layout optimizado para desktop y móvil, priorizando el mensaje y el CTA en pantallas pequeñas.
- **Microinteracciones**: efectos hover en botones, tarjetas, logos de clientes y enlaces de navegación.
